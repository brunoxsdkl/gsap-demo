# GSAP Demo

Projeto teste com animacoes GSAP (Core + Timeline + ScrollTrigger) hospedado no Vercel.

- `gsap.to / from / stagger` - animacao de entrada + dots infinitos
- `gsap.timeline` - sequenciamento de intros
- `ScrollTrigger` - reveal em cascata + pin com scrub (barra de progresso)
- `gsap.utils.clamp` - clamp de valor no onUpdate
- `prefers-reduced-motion` - respeita usuarios com movimento reduzido

## Publicar

```bash
npx vercel --prod
```
